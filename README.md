# SNX Snack Rush

Mobiele endless runner voor SNX (snxfood.com). Eén bestand: `index.html`, geen build nodig.

- Swipe links/rechts: wissel van baan
- Swipe omhoog of tik: spring over appels en kiosken
- Swipe omlaag: rol (plet appels) of val snel naar beneden
- Ontwijk de SNX-trucks
- Vang bitterballen (+10), kroketten (+25) en hamburgers (+50); 25 snacks = Turbo

Lokaal spelen: open `index.html` in een browser. Desktop: pijltjestoetsen of WASD + spatie.
